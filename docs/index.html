Hermes dashboard themes

Every theme in this repository, rendered from its YAML with the measured contrast. The values below are read out of themes/*.yaml by tools/build-gallery.py — nothing here is typed in by hand.

Repository · Colour board · Install instructions

Contrast is measured against the surface the colour actually sits on: text against the card, the button label against its fill, muted text against muted. Targets: 4.5:1 for text, 3.2:1 for a button label. Tinted chips composite further — measure the real page for those (references/contrast-checking.md in the skill).
